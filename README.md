# 🐢 Python Turtle Graphics - Turtle Race Bet Game

Welcome to the **Turtle Race Bet** project from the Python Turtle Graphics Series! 🚀

This interactive application creates a graphical race track with six multi-colored turtles. Users are prompted via a GUI popup to place a bet on which turtle will win before the race begins with randomized speed mechanics.

## 🌟 Key Features
- **GUI Text Input:** Interactive popup window asking for user predictions (`screen.textinput`).
- **Object State & Instances:** Managing multiple independent `Turtle` objects using Python lists.
- **Random Movement:** Utilizes the `random` module to simulate organic race progression.
- **Win/Loss Logic:** Detects screen boundary crossing to declare the winning turtle and check against user input.

## 🛠️ Requirements
- Python 3.x (Built-in `turtle` and `random` libraries used).
